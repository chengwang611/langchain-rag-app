**Capital Market Risk Review AI Agent Platform — RBC Capital Markets** | Python, LangGraph, LangChain, OpenAI GPT-4o-mini, FastAPI, PySpark, Docker, PostgreSQL/pgvector

- Architected a **two-pipeline multi-agent LangGraph system** for RBC Capital Markets supporting multi-fund risk report ingestion and on-demand AI-driven review: (1) a **batch ingestion pipeline** (`embedding_process`) that performs semantic chunking, embedding, and persistence of fund documents via PySpark; (2) an **on-demand review pipeline** (`review_process`) that retrieves fund-scoped context and orchestrates four specialized AI agents — decoupling expensive embedding cost from retrieval and ensuring strict fund-level data isolation

- Designed and implemented a **semantic recursive chunking strategy** using `RecursiveCharacterTextSplitter` with approximate token budgeting, section-title inference, and configurable guardrails — replacing naive character-window splitting to preserve risk narrative boundaries (headings, paragraphs, clauses) and improve retrieval attribution for capital-market documents

- Built a **vector backend abstraction layer** (`VectorStoreBackend` protocol) supporting three interchangeable backends: `InMemoryFundVectorStore` (local dev), `FileFundVectorStore` (JSONL persistence), and `PGVectorFundStore` (PostgreSQL/pgvector production) — with automatic write-strategy selection (driver-local vs. distributed executor writes) based on backend capability

- Implemented a **Regulatory Compliance Agent** (`compliance_agent.py`) with three LangChain tools (`check_basel_threshold`, `get_xxx_risk_appetite`, `generate_remediation_recommendation`) that cross-reference extracted risk findings against Basel III/IV thresholds (BCBS 352/325/238, SR 11-7) and internal risk appetite limits, auto-generating remediation actions with owner, SLA, and regulatory reference

- Built a **Market Sensitivity Analysis Agent** (`market_agent.py`) with three quantitative tools (`calculate_var_delta`, `estimate_cva_exposure`, `calculate_rwa_impact`) that enrich each finding with 99%/10-day VaR + Basel III IMA capital charges, CVA via EPE × PD × LGD (BCBS 325), and RWA under the Standardised Approach (BCBS 424/CRR2)

- Implemented a **Risk Escalation Agent** (`escalation_agent.py`) with four notification tools (`classify_findings_by_severity`, `send_slack_notification`, `send_email_notification`, `create_servicenow_ticket`) that classify findings by severity and autonomously route critical findings to senior risk officers via Slack, email, and ServiceNow P1/P2 incident tickets

- Implemented a **Human-in-the-Loop (HITL) interrupt pattern** using LangGraph checkpointing (`thread_id`), enabling risk analysts to approve, edit, or reject AI-generated findings — enriched with compliance breach flags, VaR/CVA/RWA metrics, and escalation log — before finalization

- Designed a typed **shared state contract** (`ReviewState` TypedDict, 17 fields in `models.py`) covering both pipelines, enforcing clean interfaces between ingestion, retrieval, LLM analysis, agent enrichment, HITL, and finalization stages

- Deployed the review pipeline as a **production REST API** (`api.py`, FastAPI) with four endpoints (`POST /review/start`, `POST /review/{thread_id}/resume`, `GET /review/{thread_id}/status`, `GET /health`) with Pydantic request validation and resumable review threads

- Containerized the system into **two separate Docker images** (`review-api` for continuous serving, `embedding-job` for scheduled batch processing) with documented deployment paths for OpenShift Spark Operator + Airflow DAG and Azure Databricks Workflows

- Authored a comprehensive **production roadmap** covering immutable audit trails, multi-jurisdiction regulatory rules (OSFI/PRA/ECB), RBAC + Azure AD SSO, live Bloomberg market data feeds, finding lifecycle management, stress testing scenarios, and multi-region DR
